# Video Compressor 🎬

Сжатие видео до нужного размера **с гарантированным попаданием в лимит** — например, «впихнуть ролик в 10 МБ для Telegram/почты». Программа сама подбирает битрейт, оценивает результат и при необходимости делает повторный прогон.

Работает на FFmpeg (H.264 + AAC), интерфейс на русском.

### Возможности интерфейса

- **Всё на одном экране** — файлы, параметры и панель действия видны одновременно: ничего не надо «искать» по разделам.
- **Очередь из нескольких файлов** — добавьте сколько угодно видео одним диалогом (мультивыбор) и сжмите их одним нажатием кнопки.
- **Drag-and-drop** — перетащите видеофайлы прямо в окно (Windows).
- **Выбор кодировщика** — CPU x264 или аппаратное ускорение NVIDIA NVENC / Intel QSV / AMD AMF (с автоопределением и фолбэком на CPU). Аппаратные кодеры работают в 10–20 раз быстрее.
- **Точное попадание в размер** — опциональное двухпроходное кодирование: битрейт распределяется по кадрам разумнее, размер попадает в лимит почти всегда с первой попытки.
- **Авторесолюшн** — если битов на пиксель не хватает, видео само уменьшается до выгодного разрешения (лестница 1080p → 720p → 480p): качество получается лучше, чем «каша» на полноразмере; можно задать лимит вручную (≤2160p … ≤480p).
- **Аудио без перекодирования** — если исходный аудиопоток умещается в бюджет, он копируется как есть (без потерь качества и быстрее).
- **Предупреждение о низком битрейте** — жёлтая строка «Оценки», если результат будет «мыльным».
- **GPU-отрисовка с настоящим сглаживанием** — интерфейс на Dear PyGui (DirectX), края кнопок и скругления рисуются гладко, без «пиксельных лесенок».
- **Кнопки-«пузырьки»** — скруглённая форма с тонкой светлой кромкой и подсветкой при наведении.
- **Резиновая вёрстка** — панели пересчитываются при каждом изменении размера окна: панель файлов растягивается, нижний док прижимается к краю, ничего не пропадает за границей.
- **Честная оценка** — до сжатия показывается, сколько примерно получится, какой потребуется видеобитрейт и какие файлы уменьшатся в разрешении.
- **Прогресс в нижнем доке** — проценты, «осталось ~01:12», номер текущего файла, скорость кодирования; док с кнопками «Сжать видео» / «Отмена» всегда на виду.
- **Панель «Подробности»** — расчёт битрейта и лог; автоматически раскрывается при ошибке и запоминается между запусками.
- **Настройки запоминаются** — целевой размер, скорость, кодировщик, разрешение, 2 прохода и папка сохранения.
- **Горячие клавиши** — `Enter` — сжать, `Esc` — отмена, `Ctrl+O` — добавить файлы.
- **«Открыть» у каждого файла** — кнопка появляется в строке результата; плюс общая «Открыть папку».
- **Быстрый выбор размера** — кнопки 10 / 25 / 50 / 100 МБ рядом с полем.

## 🚀 Быстрый старт для обычного пользователя

> **Python не нужен.** Достаточно одного файла.

1. Скачайте **`VideoCompressor-win64.zip`** со [страницы Releases](https://github.com/Oreshec/Video_Compressor/releases).
   *(Если релизов пока нет — соберите локально: `build_exe.bat`, см. ниже.)*
2. Распакуйте и запустите **`VideoCompressor.exe`** — двойным щелчком, одной кнопкой.
3. При первом запуске программа предложит **скачать FFmpeg** — согласитесь (один раз, ~110 МБ).
4. Выберите видео, укажите размер в МБ и нажмите **«Сжать видео»**.

Готовый файл появится рядом с исходным; кнопка **«Открыть папку»** покажет его в проводнике.

## 🎨 Интерфейс

Тёмная тема «графит + голубой акцент», **всё на одном экране**, снизу вверх:

1. **Панель файлов** — заголовок с кнопками «Добавить…» и «Очистить»,
   сводка («Файлов: N»), большая зона «Перетащите видеофайлы в окно»
   (когда список пуст) или таблица со строкой каждого файла (колонка
   «Действия»: «Открыть» и «×», чтобы убрать файл). Панель занимает
   большую часть окна и растягивается вместе с ним.
2. **Параметры в три компактные строки** — размер, МБ + быстрые чипы
   10/25/50/100 и скорость; кодировщик, разрешение и «2 прохода»;
   папка сохранения. Всё перекодирование — под рукой, без прокрутки.
3. **Нижний док, прижатый к краю окна** — прогресс-линия, текущая стадия
   и в одном ряду кнопки: **«Сжать видео»** (залита акцентом), «Отмена»,
   «Открыть папку» (после завершения) и статус. Из любого места окна
   видно, чем занята программа.

Файлы добавляются тремя способами: кнопка «Добавить…», `Ctrl+O` и
перетаскиванием прямо в окно.

Вёрстка автоматически подстраивается под любой размер окна — панели
пересчитываются при каждом изменении размера, ничего не остаётся за пределами
экрана. Интерфейс полностью масштабируется под DPI Windows (125%, 150% и т. д.):
координаты мыши совпадают с элементами, шрифты и размеры растянуты до
системного масштаба. Приложение может быть запущено в нескольких копиях —
drag-and-drop всегда попадает именно в окно того процесса, куда бросили файлы.

## 💻 Запуск из исходников (для разработчиков)

Единственная зависимость GUI — [Dear PyGui](https://dearpygui.readthedocs.io/), ядро и консольный режим работают на стандартной библиотеке:

```bash
pip install dearpygui   # достаточно один раз (в exe уже включён)
```

```bash
# GUI (или просто двойной клик по Run.bat)
python gui_compressor.py

# То же самое через пакет
python -m video_compressor

# Консольный режим
python compress_video.py video.mp4 -s 10
```

Если FFmpeg не установлен — в GUI нажмите «Скачать» при предложении, либо в консоли:

```bash
python compress_video.py video.mp4 --download-ffmpeg
```

### Параметры консольной версии

| Параметр | Описание |
|----------|----------|
| `input` | Входной видеофайл (или `-i путь`) |
| `-o`, `--output` | Выходной файл (по умолчанию: `имя_compressed.mp4`) |
| `-s`, `--size` | Целевой размер в МБ (по умолчанию: 10) |
| `-p`, `--preset` | Пресет скорости: `ultrafast` … `veryslow` (по умолчанию `veryfast`) |
| `--encoder` | Кодировщик: `libx264`, `h264_nvenc`, `h264_qsv`, `h264_amf` |
| `--resolution` | Ограничение разрешения: `source`, `auto` или высота (`1080`, `720`, `480`…) |
| `--two-pass` | Двухпроходное кодирование: точнее в целевой размер, но вдвое дольше |
| `-q`, `--quiet` | Только ошибки |
| `--download-ffmpeg` | Скачать FFmpeg в папку программы, если его нет |
| `--version` | Версия программы |

Примеры:

```bash
python compress_video.py video.mp4             # до 10 МБ
python compress_video.py video.mp4 -s 5        # до 5 МБ
python compress_video.py video.mp4 -s 25 --resolution auto --two-pass
python compress_video.py video.mp4 -o out.mp4 -s 50 --encoder h264_nvenc
```

## ❓ Как это работает

1. **Анализ** — `ffprobe` определяет длительность, разрешение, битрейты потоков.
2. **Расчёт** — по целевому размеру считается видеобитрейт с запасом ~8% (`SAFETY_FACTOR = 0.92`); аудио ограничивается долей бюджета и копируется без перекодирования, если умещается.
3. **Кодирование** — FFmpeg кодирует в H.264 (x264 или аппаратный NVENC/QSV/AMF), программа показывает прогресс и оставшееся время. При сбое аппаратного кодера выполняется автоматический повтор через x264.
4. **Коррекция** — если фактический размер не влез в лимит, битрейт пересчитывается по реальному превышению и идёт повторный прогон (до 3 попыток). Опциональный **2-pass** режим распределяет биты по кадрам заранее и почти всегда попадает в лимит с первого прохода.
5. **Разрешение** — в режиме `auto` (или по лимиту) видео даунскейлится, когда битов на пиксель слишком мало: `{TARGET_BITS_PER_PIXEL = 0.06}` и лестница высот 2160 → 1440 → 1080 → 720 → 540 → 480.

Итоговый размер может незначительно отличаться из-за особенностей кодека; кодек упирается в минимальный битрейт только для экстремальных лимитов (час видео в 1 МБ).
