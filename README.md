# Video Compressor 🎬

Сжатие видео до нужного размера **с гарантированным попаданием в лимит** — например, «впихнуть ролик в 10 МБ для Telegram/почты». Программа сама подбирает битрейт, оценивает результат и при необходимости делает повторный прогон.

Работает на FFmpeg (H.264 + AAC), интерфейс на русском.

### Возможности интерфейса

- **Очередь из нескольких файлов** — добавьте сколько угодно видео одним диалогом (мультивыбор) и сжмите их одним нажатием кнопки.
- **GPU-отрисовка с настоящим сглаживанием** — интерфейс на Dear PyGui (DirectX), края кнопок и скругления рисуются гладко, без «пиксельных лесенок».
- **Чёрный минимализм** — чистый чёрный фон, тонкие разделители вместо рамок.
- **Кнопки-«пузырьки»** — скруглённая форма с тонкой светлой кромкой и подсветкой при наведении.
- **Честная оценка** — до сжатия показывается, сколько примерно получится и какой потребуется видеобитрейт.
- **Прогресс с остатком времени** — проценты, «осталось ~01:12», номер текущего файла.
- **Панель «Подробности»** — расчёт битрейта и лог FFmpeg (автоматически раскрывается при ошибке).
- **Настройки запоминаются** — целевой размер, скорость и папка сохранения между запусками.
- **Горячие клавиши** — `Enter` — сжать, `Esc` — отмена, `Ctrl+O` — добавить файлы.
- **Кнопка «Открыть папку»** появляется сразу после успешного сжатия.

## 🚀 Быстрый старт для обычного пользователя

> **Python не нужен.** Достаточно одного файла.

1. Скачайте **`VideoCompressor-win64.zip`** со [страницы Releases](https://github.com/Oreshec/Video_Compressor/releases).
   *(Если релизов пока нет — соберите локально: `build_exe.bat`, см. ниже.)*
2. Распакуйте и запустите **`VideoCompressor.exe`** — двойным щелчком, одной кнопкой.
3. При первом запуске программа предложит **скачать FFmpeg** — согласитесь (один раз, ~110 МБ).
4. Выберите видео, укажите размер в МБ и нажмите **«Сжать видео»**.

Готовый файл появится рядом с исходным; кнопка **«Открыть папку»** покажет его в проводнике.

## 💻 Запуск из исходников (для разработчиков)

Единственная зависимость GUI — [Dear PyGui](https://dearpygui.readthedocs.io/), ядро и консольный режим работают на стандартной библиотеке:

```bash
pip install dearpygui   # достаточно один раз (в exe уже включён)
```

```bash
# GUI (или просто двойной клик по Run.bat)
python gui_compressor.py

# То же самое через пакет
python -m video_compressor

# Консольный режим
python compress_video.py video.mp4 -s 10
```

Если FFmpeg не установлен — в GUI нажмите «Скачать» при предложении, либо в консоли:

```bash
python compress_video.py video.mp4 --download-ffmpeg
```

### Параметры консольной версии

| Параметр | Описание |
|----------|----------|
| `input` | Входной видеофайл (или `-i путь`) |
| `-o`, `--output` | Выходной файл (по умолчанию: `имя_compressed.mp4`) |
| `-s`, `--size` | Целевой размер в МБ (по умолчанию: 10) |
| `-p`, `--preset` | Пресет скорости libx264: `ultrafast` … `veryslow` (по умолчанию `veryfast`) |
| `-q`, `--quiet` | Только ошибки |
| `--download-ffmpeg` | Скачать FFmpeg в папку программы, если его нет |
| `--version` | Версия программы |

Примеры:

```bash
python compress_video.py video.mp4             # до 10 МБ
python compress_video.py video.mp4 -s 5        # до 5 МБ
python compress_video.py video.mp4 -o out.mp4 -s 50
```

## 🛠 Сборка своего exe (одна кнопка)

Нужен только Python 3.9+ (сам exe работает без него):

```
build_exe.bat
```

Скрипт установит зависимости и PyInstaller и создаст `dist\VideoCompressor.exe`.

Автосборка в CI: при пуше тега `v*` GitHub Actions собирает exe и публикует релиз автоматически (`.github/workflows/release.yml`).

## ❓ Как это работает

1. **Анализ** — `ffprobe` определяет длительность, разрешение, битрейты потоков.
2. **Расчёт** — по целевому размеру считается видеобитрейт с запасом ~8% (`SAFETY_FACTOR = 0.92`), а аудио ограничивается долей бюджета.
3. **Кодирование** — FFmpeg кодирует в H.264/AAC, программа показывает прогресс и позволяет отменить.
4. **Коррекция** — если фактический размер не влез в лимит, битрейт пересчитывается по реальному превышению и идёт повторный прогон (до 3 попыток).

Итоговый размер может незначительно отличаться из-за особенностей кодека; кодек упирается в минимальный битрейт только для экстремальных лимитов (час видео в 1 МБ).
